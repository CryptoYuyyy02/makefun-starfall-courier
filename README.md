**Starfall Courier** — a neon arcade dodger. Pilot a glowing ship through an asteroid field, collect energy crystals, and chain combos for score. Crystals restore hull; a shield flare protects you briefly after a hit. A complete, original 2D canvas game with a title screen, HUD, pause, game over and restart.

## Run it

```sh
node serve.ts    # then open http://localhost:8080
```
